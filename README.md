# سوق المنتجات — تطبيق أندرويد

تطبيق أندرويد يفتح متجر «سوق المنتجات» على:
https://www.commerce-dz.com/

## الميزات
- أيقونة تكيفية (Adaptive) تدعم أيقونات Android 13+ المتناسقة، وشاشة بداية بهوية المتجر
- حفظ جلسة تسجيل الدخول ("تذكرني")
- رفع الصور والملفات من داخل صفحات الموقع (مثل صور المنتجات)
- تحميل الملفات (فواتير، تصدير...) عبر مدير التحميلات
- سحب للأسفل للتحديث، شريط تحميل، شاشة "لا يوجد اتصال"
- زر الرجوع يتنقل داخل الموقع، والروابط الخارجية (اتصال، بريد، واتساب...) تُفتح في تطبيقاتها

## الحصول على APK
1. ارفع كل الملفات إلى GitHub (فرع `main`).
2. تبويب **Actions** ← **Build Android APK** ← انتظر الاكتمال.
3. نزّل `Souq-APK` من **Artifacts**، فك الضغط، وثبّت `app-debug.apk`
   (فعّل "السماح بالتثبيت من مصادر غير معروفة").

## التخصيص
- رابط الموقع: الثابت `TARGET_URL` في `app/src/main/java/com/commercedz/market/MainActivity.java`
- الأيقونة: `app/src/main/res/drawable/ic_launcher_*.xml`، وأيقونة المتجر 512×512 في `store/icon-512.png`
